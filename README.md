# 東方貓貓狗 · Feline Faith

以東方 Project 彈幕玩法為靈感的非官方同人網頁遊戲。

操控博麗靈夢 A 誘導裝備，直闖帝國大學，與稱號為「可愛狗」的玳瑁貓展開彈幕對決。

**[立即遊玩](https://touhou-cat-dog-barrage.funibis12.chatgpt.site)**

## 故事與關卡

> 禁鐘響起，帝國大學的結界悄然甦醒。
> 守在校門前的神祕存在，自稱「可愛狗」。
> 靈夢：「……妳明明就是貓吧？」

- **關卡**：帝國大學
- **日文名稱**：帝國大学 — 禁鐘のアカデミア
- **副題**：第零結界・叡智ノ果テニ眠ル獣
- **Boss**：玳瑁貓／可愛狗
- **戰鬥 BGM**：東方疾走貓

入場先顯示關卡名稱與 BGM 字幕，再進行簡短對話並開始 Boss 戰，沒有前置雜魚關。完整通關後播放結局、作者頁與「and you」感謝頁，最後顯示成績。

## 遊戲特色

- 靈夢 A 誘導射擊，搭配低速移動、判定點與炸彈靈擊。
- Boss 三條命，每條命各有一段非符與一張符卡，共六段攻擊。
- Easy、Normal、Hard、Lunatic 四種難度，以及加強版 Extra 挑戰。
- 支援符卡練習、操作重播、遊玩紀錄與最高分儲存。
- 使用貓照片製作標題畫面，並以大學照片作為戰鬥背景。
- 原創 Web Audio 合成配樂，包含標題曲、戰鬥曲與 ED 變奏。
- 支援鍵盤、觸控操作、自動射擊與全螢幕。

## 操作方式

| 按鍵         | 功能                             |
| ------------ | -------------------------------- |
| 方向鍵／WASD | 移動                             |
| Z            | 射擊、主選單確認、對話與 ED 翻頁 |
| Enter        | 主選單確認、對話與 ED 翻頁       |
| Shift        | 低速移動並顯示判定點             |
| X            | 使用炸彈靈擊                     |
| Esc          | 暫停／繼續遊戲                   |

手機和平板建議橫向遊玩。可拖曳戰鬥區移動角色並射擊，也可使用畫面下方的觸控按鈕。

第一次遊玩需要點擊選單或按鍵，瀏覽器才會開始播放音樂。可在 **Option** 調整音量及自動射擊，或使用右上角音樂按鈕切換聲音。

### 遊玩提示

- 角色受擊判定是身體中央的小圓點；靠近彈幕但未碰到判定點時，可以擦彈加分。
- Boss 三條命與玩家殘機分開計算，分別顯示在戰鬥區上方與右側資訊欄。
- 追蹤彈只會在一定時間內轉向；觀察分身的落點預告，提早規劃移動路線。
- 耐久符卡期間 Boss 無敵，重點是存活到倒數結束。

## Boss 攻擊

| Boss 命數 | 非符                     | 符卡與機制                                                                                                             |
| --------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| 第一條命  | 非符「奇跡の星詠み」     | **貓符「ババ狗」**：分身預告落點後突進，搭配限時追蹤御札。                                                       |
| 第二條命  | 非符「禁鐘に降る五芒星」 | **時符「禁鐘に踊る双つの影」**：45 秒耐久；追擊分身逐步增加至兩隻，沿途留下延遲爆裂彈。Boss 免疫射擊及炸彈傷害。 |
| 第三條命  | 非符「帝都の星辰結界」   | **終符「帝國を翔ける猫神の神徳」**：交替發射多色米粒彈環，隨血量下降及時間經過，提高密度、速度與發射頻率。       |

非符以旋轉五芒星彈幕為主。各段攻擊是本作自行設計的致敬玩法，並非原作符卡的逐幀重製。

## 主選單

| 選項           | 內容                                       |
| -------------- | ------------------------------------------ |
| Game Start     | 選擇難度，開始完整 Boss 戰。               |
| Extra Start    | 直接挑戰提高彈速與密度的 Extra 模式。      |
| Practice Start | 選擇三張符卡之一進行練習。                 |
| Replay         | 播放最近一次完成出擊的操作重播。           |
| Player Data    | 查看出擊、通關、符卡收取及最高分紀錄。     |
| Music Room     | 試聽「貓影下的博麗神社」與「東方疾走貓」。 |
| Option         | 調整音樂音量與自動射擊。                   |
| Quit           | 顯示離開提示；可自行關閉分頁。             |

ED 每幕自動停留 9 秒，也可按 Z／Enter 或點擊按鈕翻頁、跳過。符卡練習與 Replay 結束後直接顯示成績，不播放 ED。

## 本機執行

本作使用原生 HTML、CSS、JavaScript，不需要安裝 npm 套件或進行建置。

下載專案後，可直接用瀏覽器開啟 `dist/index.html`。也可以在專案根目錄啟動 Python 靜態伺服器：

```sh
python -m http.server 5173 --directory dist
```

接著開啟 [http://localhost:5173](http://localhost:5173)。若系統的 Python 指令為 `python3`，請將上方指令中的 `python` 換成 `python3`。

部署至其他靜態網站服務時，網站根目錄應設為 `dist`，並保留其中的 `assets` 資料夾及檔案相對路徑。

## 驗證

若已安裝 Node.js，可在專案根目錄執行：

```sh
node --check dist/game.js
node check.cjs
```

檢查涵蓋關卡入場與對話、三條 Boss 命、星彈與追蹤彈、耐久無敵及倒數、炸彈清彈、終符強化、確定性 Replay，以及 ED 到成績畫面的流程。

## 紀錄與相容性

遊玩紀錄透過瀏覽器的 `localStorage` 儲存，沒有帳號同步或雲端存檔。不同裝置、瀏覽器及網站網址的紀錄不會互通；清除網站資料後，紀錄也會一併清除。

Replay 僅保留最近一次已完成出擊的紀錄。彈幕邏輯更新後，舊版本的重播可能無法播放。練習模式不計入完整通關次數。
